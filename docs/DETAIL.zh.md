# Markdown 审阅模式

在右边栏的预览窗格里给 Markdown 文稿加一层审阅：选中文字写批注，Agent 按批注
返工，改动高亮并逐条回执。

## 它做什么

打开 `.md` 文件，右边栏的渲染器下拉里除了产品自带的 Markdown 视图，还多一个
**审阅**。审阅视图读起来像一份文档：Markdown 正常渲染，标记淡出，点一下某一段
就展开成源码。

选中一段，选区旁会浮出一个小工具栏。**批注** 打开输入框写下这段哪里不对，
**锁定** 把它冻住。批注用下划线标出，锁定用另一种下划线；点其中任意一个都会
就地浮出批注内容，可以改，也可以删。

提交只发一条消息给 Agent。Agent 读批注、产出改动、逐条回执；面板随后把改动的
块和回执显示在各自的批注旁。

## 为什么批注就是指令

插件把批注当**指令**，而不是"帮我把话说得更好些"的请求。所以 Agent 是被程序
检查的，不是被信任的：改动落在批注覆盖范围之外会被拒绝，锁定区必须逐字节保持
原样。

## 自定义样式

面板是插件自己渲染的，所以**你自己的 CSS 就是把它调成你想要的样子的方式** ——
更大的阅读字号、不同的强调色、你自己的纸。

把文件放在 **`~/.dsh/review.css`**，下次打开面板就会加载。想用别的位置的���件，
把插件的 `stylesheet` 配置项设成那个路径（插件的配置页可以填），文件放在 Host
能读到的任何地方都行。

样式表按原样生效，所以它的规则会作用到整个页面。面板自己的名字是稳定的，可以
直接选择：

| 名字 | 是什么 |
| --- | --- |
| `markdown-review-mode-root` | 整个面板 |
| `markdown-review-mode-toolbar` | 文档上方的工具栏 |
| `markdown-review-mode-editor` | 文档本身 |
| `markdown-review-mode-floating` | 选中时浮出的工具栏 |
| `markdown-review-mode-popup` | 显示单条批注的浮窗 |
| `cm-review-strong` / `cm-review-em` / `cm-review-code` | 粗体、斜体、行内代码 |
| `cm-review-h1` … `cm-review-h6` | 各级标题 |
| `cm-review-marker` | 淡化的结构标记 |
| `cm-review-highlight` / `cm-review-lock` / `cm-review-changed` | 批注、锁定、改动过的块 |
| `cm-review-bullet` / `cm-review-table` | 列表符号、表格 |

比如想用更大的字号阅读：

```css
.markdown-review-mode-editor {
  font-size: 16px;
  line-height: 1.7;
}
```

## 它不做什么

- 没有版本历史、没有 diff 视图、不能整篇回滚；只能把单个块恢复成审阅时的样子。
- 批注不跨审阅会话的重启存活。**你自己对文字的改动会存下来** —— 它放在项目
  之外，面板再打开时会恢复。
- 代码块、表格、HTML 块和图片按整块处理：选到它们里面会吸附到整块。
- Agent 不能改动没有被任何批注覆盖的块。
- 脚注的定义留在源码所在的位置，不会被移到文档末尾。

## 需要什么

插件需要一个工作目录里放着该文档的会话，以及为该会话挂载的文件系统提供方。
在 `read-only` 沙箱模式下无法应用审阅，因为文档写不进去。
